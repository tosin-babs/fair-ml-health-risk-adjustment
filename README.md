# Interpretable and Fair Machine Learning for Health-Cost Prediction and Risk Adjustment: A Reproducible Benchmark and Open-Source Toolkit

A reproducible benchmark of interpretable and fairness-aware machine-learning methods for health-cost prediction and risk adjustment, released as an open-source toolkit.

**Status.** Planned. Capstone; produces a public software tool. Code and results will be published here as the
analysis is completed.
